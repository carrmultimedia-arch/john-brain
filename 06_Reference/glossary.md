# Glossary

Compiled from Claude's memory notes on 2026-10-15. Check against the source notes before relying on fine detail.

**Architect + Executor**: John's pipeline. An AI architects and specifies; other tools execute the code; John approves and pastes. See [[how-to-work-with-john]].

**Business Archaeology**: LEGAiSEE's methodology. A forensic excavation of a company's own history (abandoned assets, proven-but-forgotten messages, "Golden Era" patterns), rebuilt into a present-day authority system. It recovers proven messages; it does not invent new ones. John's goal is for the phrase to become as recognized as "SEO".

**Phase 0 / Shallow Dig / mini-dig**: The entry-point forensic pass. Produces an "Estimated Golden Era", one "Abandoned Asset", a "Competitive Gap" and one inflection point, plus an excavation brief used to choose the next Exhibit. It is the lead-magnet entry to the funnel, not the whole business.

**Exhibit System (Exhibits A to G)**: LEGAiSEE's service tiers after Phase 0, from project work to monthly/quarterly enterprise retainers. Pricing ladder is in [[legaisee-services]] and [[legaisee-master-system-law]].

**Exhibit Zero**: John's own production career, used as the proof-of-concept on the LEGAiSEE practitioner page.

**Full Excavation / 40+ channels**: The complete dig across a fixed taxonomy of 40+ channels. See [[legaisee-excavation-channels]].

**Authority Marketing System**: The end product delivered to a client after excavation and evidence grading.

**Hierarchy of Truth (Tier 1 to 4) and 3-Source Rule**: LEGAiSEE's evidence-grading method. A real scoring engine was built 9/6/26 (`engine/hierarchy_of_truth_engine.php`).

**Dig Review**: A human approve / flag / reject step before anything becomes accepted business memory (from the Excavator V1 design, currently parked).

**Excavator**: A proposed first "AI employee" for LEGAiSEE. Parked 9/29/26. See [[legaisee-ai-excavator-v1]].

**Command Center**: The PHP/MySQL LEGAiSEE application on John's server. `shell.php` is the live entry point (the "Grand Lobby"). See [[legaisee-command-center]].

**tree_nodes / node_id / identity layer**: The database table and key that gives every project and client one identity. The whole pipeline is meant to key off `node_id`.

**WO (work order)**: A bounded, self-contained task written for an executor. WO numbers (WO-1 to WO-20+) are logged in [[legaisee-work-orders]].

**Bible (doc)**: A running reference document for a build (for example the ProjectManager Bible).

**Macro view**: Keeping the whole plan in sight. John's ruling (9/1/26): postponed items are sequenced, never dropped.

**Server is truth, git is backup**: The live server is the real version of the code. GitHub is only a manual backup that may lag.

**CAMERA**: The media/content education course. Six dimensions (Character Positioning, Audience Targeting, Monetization Design, Engagement Engineering, Repurposing Infrastructure, AI Acceleration). Also the tenth framework of the LEGAiSEE methodology as the "CAMERA Authority System". See [[camera-course]], [[legaisee-services]].

**ATLAS-TV**: Planned authority-marketing course (the name's first spelling stood for Authority, Tactics, Leadership, Architecture, System, Traffic, Viral-Loop, but that TOC was discarded). See [[atlas-tv-course]].

**Presenter site / scrollytelling**: The cinematic 3D web presentation used instead of slides in CAMERA's live Zoom cohorts. See [[camera-presenter-site]].

**Freebuff, Devin, Windsurf, Cline**: AI coding tools John has used as executors. See [[dev-workflow]].

**CFRS (Company-First Reverse Job Search)**: A proposed method for the job-hunt dashboard. See [[jobhunt-reverse-search-methodology]].

**Forensic CAC**: True customer-acquisition cost, corrected rather than estimated. Part of LEGAiSEE's value framing (minimum 3:1 LTV:CAC).
