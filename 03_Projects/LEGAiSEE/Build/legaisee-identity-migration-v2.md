## FINDING: real `node_attributes` table is itself an orphaned leftover, NOT usable as a generic attributes table

This is a per-node task/kanban-style tracker shape, NOT a flexible key/value attributes table — completely different purpose than the name suggests.
- Has real data (16KB) but ZERO live code references it anywhere in the current codebase (confirmed via full-repo grep for the literal string "node_attributes" — no matches in any .php file). 
- Creation date (Jun 24, 2026) lines up with the stale 6/26 governance note found earlier ("tree_nodes, node_attributes, chat_ingest were created mid-session before realizing memory_ingest's processed column already covers the same job") — this table is very likely a genuine leftover from that same abandoned early planning attempt. tree_nodes survived and got repurposed for real in WO-18 (9/1); node_attributes just got left behind with its old test data, forgotten, disconnected ever since.
- DECISION: do not reuse this table or its name for the new client-details design (renamed to `node_details` instead, see above) to avoid confusion with this old orphaned one. node_attributes itself flagged for future cleanup (low priority, not urgent, not touched yet).
