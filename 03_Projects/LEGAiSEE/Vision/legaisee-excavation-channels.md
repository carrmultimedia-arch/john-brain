## Cross-model verification vs. cross-model agreement (8/19)
- [stated] Raised a real methodological concern after seeing a bad AI response (genealogy-focused, wrong business category, likely fabricated citations): if using a pipeline of different LLMs for different roles (discovery/analysis/validation), a bad finding at the discovery stage could pass downstream unchecked, since later stages may validate reasoning rather than re-checking the underlying raw fact
- [stated] Standing clarification locked: cross-model agreement (multiple LLMs independently saying the same thing) is a triage/confidence signal, not itself verification — models can converge on a shared false claim from overlapping training data just as easily as on a true one found via real search. Only a checkable primary source (URL, archive snapshot, quote) actually satisfies the existing 3-Source Rule / Bedrock Pledge; agreement without a citation doesn't count as one of the sources
- [stated] Reconciled with the already-documented 4-query parallel + confidence-tagging method in this file: that method already does this correctly (synthesis table, ✅/⚠️/❓ confidence marks by source count, 30-min human spot-check) — the risk is only if a future pipeline build loses that redundancy by chaining single-pass discovery→analysis→validation instead of preserving the parallel-comparison + citation-required discipline
- [stated] Working rule for future pipeline builds: redundant same-query multi-model checks aren't needed on every search (too costly, defeats automation gains) — reserve them for load-bearing/high-value claims (the "gemstone" asset any pitch hinges on), and require a real source citation before any claim can flow downstream into Findings/Authority System composition regardless of how many models agreed on it
- [stated] Confirmed this rule applies directly to the RAG-vault design in [[legaisee-authority-engine]]: the vault's synthesis step should refuse to produce any claim that doesn't trace back to a stored chunk carrying a real source tag — citation-required is a hard gate on the composer, not just a discipline for the manual dig phase
